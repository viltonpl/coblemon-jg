# Servidor Cobblemon - Comandos Rápidos

## 🚀 INICIAR SERVIDOR

### Opção 1: Com verificações automáticas (RECOMENDADO)
```bash
./start-server.sh
```

### Opção 2: Comando direto
```bash
java -Xmx8G -Xms4G -jar fabric.jar --nogui
```

## 🔍 DIAGNOSTICAR PROBLEMAS

```bash
./diagnose-server.sh
```

Verifica mods, bibliotecas, logs e estrutura do servidor.
